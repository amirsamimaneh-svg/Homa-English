# هما (Homa) — پلتفرم آموزش زبان و خلبانی

پیاده‌سازی کامل رابط کاربری پلتفرم آموزشی «هما» بر اساس دیزاین‌سیستم UI/UX ارائه‌شده — شامل وب‌سایت معرفی، اپلیکیشن موبایل، سامانه آموزش آنلاین (LMS) و ماژول یادگیری گیمیفای‌شده.

> **وضعیت:** فاز اول (رابط کاربری با دیتای دمو). همه صفحات با داده‌ی نمونه‌ی داخل کد کار می‌کنند؛ بک‌اند واقعی در فاز بعدی اضافه می‌شود. لایه‌ی داده (`src/lib/data.ts`) طوری نوشته شده که جایگزینی دمو با API واقعی ساده باشد.

## تکنولوژی

- **Next.js 15** (App Router) + **TypeScript**
- **Tailwind CSS** با دیزاین‌توکن‌های سفارشی هما
- فونت **Vazirmatn** (فارسی) و **Space Grotesk** (اعداد/انگلیسی) از طریق `next/font`
- کاملاً **راست‌به‌چپ (RTL)** و فارسی

## اجرا

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # بیلد پروداکشن
```

## نقشه‌ی صفحات (Routes)

### وب‌سایت معرفی (دسکتاپ)
| مسیر | صفحه |
|---|---|
| `/` | خانه |
| `/about` | درباره ما |
| `/courses/language` | لیست دوره‌های زبان (با فیلتر و مرتب‌سازی زنده) |
| `/courses/pilot` | لیست دوره‌های خلبانی |
| `/courses/[slug]` | جزئیات دوره (سرفصل آکاردئونی، مدرس، نظرات) |
| `/instructors` | اساتید |
| `/blog` | بلاگ (با فیلتر دسته‌بندی) |
| `/contact` | تماس با ما (فرم مشاوره) |
| `/faq` | سوالات متداول |

### اپلیکیشن موبایل
| مسیر | صفحه |
|---|---|
| `/app/auth` | ورود / ثبت‌نام / تایید کد پیامکی |
| `/app/checkout` | انتخاب پلن / پرداخت / تایید (با کد تخفیف `HOMA10`) |
| `/app/account` | دوره‌های من / فاکتورها / پروفایل |

### سامانه آموزش آنلاین (LMS)
| مسیر | صفحه |
|---|---|
| `/lms/dashboard` | داشبورد دانشجو |
| `/lms/class` | پخش کلاس |
| `/lms/quiz` | آزمون آنلاین (تعاملی) |
| `/lms/certificate` | گواهی پایان دوره |
| `/lms/instructor` | پنل مدرس |
| `/lms/admin` | پنل مدیریت |

### ماژول یادگیری گیمیفای‌شده
| مسیر | صفحه |
|---|---|
| `/learn/path` | مسیر یادگیری |
| `/learn/exercise` | تمرین (چیدن کلمات / شنیداری / گفتاری + بازخورد AI) |
| `/learn/complete` | پایان درس |
| `/learn/profile` | پروفایل و دستاوردها |

## ساختار پروژه

```
src/
  app/                 # صفحات (App Router)
  components/
    icons.tsx          # لوگو هما، آیکون AI (Sparkle)، آیکون‌های عمومی
    AIBadge.tsx        # نشان و کارت هوش مصنوعی (الگوی واحد کل پلتفرم)
    marketing/         # هدر، فوتر، کارت دوره، هیرو و ...
    app/               # قاب موبایل (PhoneFrame)، تب‌بارها
    panel/             # سایدبار پنل‌های ادمین/مدرس
  lib/
    data.ts            # لایه‌ی داده‌ی دمو + توابع کمکی (getter، فرمت قیمت، رقم فارسی)
```

## دیزاین‌سیستم

- **رنگ پایه:** نیوی (`#0A1F33`–`#DCE8F1`)
- **رنگ ثانویه / CTA / هوش مصنوعی:** کهربایی (`#D98E3B`)
- **نشان هوش مصنوعی:** آیکون جرقه‌ی کهربایی + پس‌زمینه کهربایی، به‌صورت کامپوننت مشترک `AIBadge` در کل پلتفرم استفاده می‌شود.
- توکن‌ها در `tailwind.config.ts` و `globals.css` تعریف شده‌اند.
